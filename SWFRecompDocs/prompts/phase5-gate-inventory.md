## Background (verified 2026-07-23 — don't re-derive)

The runtime compiles into three real execution configurations:

| Config | Defines (exact) | Frame loop |
|---|---|---|
| no-graphics | `NO_GRAPHICS` | `swf_core.c` |
| graphics-native | `USE_WEBGPU`, `OFFSCREEN_RENDER`, `NDEBUG` (+ `HEADLESS_RENDER_ENABLED` when image comparisons are on) | `swf.c` |
| browser-WASM | `__EMSCRIPTEN__` (compiler-set), `USE_WEBGPU` — and NEITHER `NO_GRAPHICS` NOR `OFFSCREEN_RENDER` | `swf.c` |

Historic bug pattern: shared code gated `#if defined(NO_GRAPHICS) ||
defined(OFFSCREEN_RENDER)` where the `#else` (= browser-WASM) is missing or
stale. A long tail of shipped-game bugs came from exactly this (see memory
topics `removemovieclip-noop-browser-wasm`, `browser-wasm-xmouse-root-only`,
`browser_wasm_frame_func_rerun`).

Raw symbol counts after the 2026-07-23 mode-consolidation work (grep hits,
not sites): `NO_GRAPHICS` — action.c 179, tag.c 147, tag_stubs.c 29,
graphics_stubs.c 16, avm2_media.c 14, tag.h 14; `OFFSCREEN_RENDER` —
action.c 133, tag.c 121, swf.c 40, render_webgpu.c 31; `__EMSCRIPTEN__` —
render_webgpu.c 24, swf.c 10, avm2_external.c 8, action.c 8. There are
**283 `#if` directives** referencing these symbols in action.c + tag.c +
swf.c alone; expect roughly 350–450 gate sites repo-wide.

Two **calibration examples** of intentional divergence (your tool must
surface these; the triage pass will mark them "intentional, documented"):

1. `swf.c` natural-wrap catch-up promotion (search
   `TRANSFORMED_BY_SCRIPT_WRAP_BACK` in swf.c): gated `#ifdef
   OFFSCREEN_RENDER` with an in-code comment explaining browser-WASM keeps
   the light wrap path (Snake restart flow).
2. `render_webgpu.c` surface creation: three-way split (offscreen / canvas /
   native SDL window) that is inherently per-config.

## The tool: `tools/gate_inventory.py`

Python 3 stdlib only. Requirements:

1. **Parse preprocessor structure** of every `.c`/`.h` under
   `SWFModernRuntime/src/` and `SWFModernRuntime/include/` (exclude
   `SWFModernRuntime/lib/`, `vendor/`) plus `SWFRecomp/wasm_wrappers/*.c`.
   Track nested `#if`/`#ifdef`/`#ifndef`/`#elif`/`#else`/`#endif` regions
   with correct nesting. Only sites whose condition mentions `NO_GRAPHICS`,
   `OFFSCREEN_RENDER`, or `__EMSCRIPTEN__` (directly, at any nesting level)
   enter the inventory.
2. **Evaluate each site's condition under the three configs** with a small
   `defined()`-expression evaluator (`!`, `&&`, `||`, parentheses,
   `defined(X)` / `defined X`, bare-macro truthiness). Macros outside the
   config sets (`WITH_AP`, `SWF_HAVE_LIBAVCODEC`, `MAX_FRAMES`, `NDEBUG` in
   non-graphics configs, etc.) evaluate as **unknown**: propagate
   three-valued logic and report the site's result as `depends(<macro>)`
   rather than guessing. Nested gates multiply: a region's effective
   condition is the conjunction of its enclosing stack.
3. **Per site, report**: file:line span, the raw condition (and enclosing
   stack if nested), non-blank/non-comment line count of each arm, and which
   configs receive code (including per-`#elif`/`#else` arm attribution).
4. **Flag list** (the actual deliverable): sites where **browser-WASM
   receives zero code while both native configs receive code** — plus a
   secondary list for the reverse (browser-only arms) and for
   graphics-native-vs-no-graphics asymmetries. Sites where browser-WASM's
   empty arm is < 3 lines from a shared fallthrough still count — absence of
   an `#else` IS the signal.
5. **Deterministic output** (stable path + line ordering) so regenerated
   inventories diff cleanly.
6. Self-test: run it on a small embedded fixture string (nested `#elif`,
   negations, unknown macros) via `--selftest`.
