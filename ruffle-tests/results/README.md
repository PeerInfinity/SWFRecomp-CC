# Cross-suite result tables

Generated by CI on every publishing `ruffle-tests.yml` run (`scripts/ci/publish_results.sh` →
`scripts/generate_results_index.py`) and merged into `master` from the `ruffle-test-results` branch. Don't edit them
by hand.

| File | What |
|---|---|
| `RUFFLE_RESULTS_GRAPHICS.md` / `_FILTERED.md` | `mode=graphics` (the per-change CI mode), every suite |
| `RUFFLE_RESULTS.md` / `_FILTERED.md` | `mode=no-graphics` (weekly canary), every suite |
| `RUFFLE_COMPARISON.md` / `_FILTERED.md` | SWFRecomp vs Ruffle pass/fail buckets. **Not CI-generated**: a 2026-05-09 snapshot from `scripts/generate_ruffle_comparison.py` (run by hand) |

`_FILTERED` excludes the tests on `ruffle-tests/ignored_tests.txt` and the per-suite ignore lists. Per-suite detail is
in each suite's `ruffle-tests/tests/swfs/<suite>/_results/`. These files lived at the repo root until repo-cleanup
slice S3 (2026-11-28).
