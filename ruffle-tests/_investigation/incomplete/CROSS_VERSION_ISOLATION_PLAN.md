# Cross-Version Isolation Plan

## Overview

When multiple SWFs of different versions are loaded together (via `loadMovie`, `loadMovieNum`, `MovieClipLoader`), each SWF version should get version-appropriate behavior. This requires three interconnected features:

1. **Per-version `_global` object** — SWF7+ movies each get their own `_global`; SWF1-6 share one
2. **Per-function SWF version tracking** — Functions remember which SWF version they were defined in
3. **DoInitAction for child SWFs** — Class initialization scripts in child SWFs must run in child context

This is the single largest cross-cutting blocker, affecting 9+ blocked plans.

**Blocks these plans:**
- LOADMOVIE_PLAN Phase 6
- GLOBALS_PLAN Phase 8 (multi-SWF enumeration tests)
- HIT_TESTING_PLAN (invalid_get_bounds_1-8)

- REGISTERCLASS_PLAN (register_class_swf6, do_init_action_child)
- CLONE_DUPLICATE_PLAN (partially)
- LOADMOVIE_REMAINING_PLAN

## Current Architecture

### Single Global Version
```c
// action.c line 531
int g_swf_version = 5;  // Set at startup from constants.h, never changes
```

All 86+ version-dependent checks in action.c reference this single global. When a child SWF5 is loaded into a parent SWF8, the child's functions execute with SWF8 semantics.

### Single Global Object
```c
// action.c line 6029
static ASObject* global_object = NULL;
static int g_global_init_done = 0;
```

Created once via `actionGetGlobalObject()` (line 16896), populated with version-gated constructors. All loaded SWFs share this single `_global`.

### ASFunction Struct (no version field)
```c
typedef struct ASFunction {
    char name[256];
    u8 function_type;
    u32 param_count;
    SimpleFunctionPtr simple_func;
    Function2Ptr advanced_func;
    u8 register_count;
    u16 flags;
    ASObject* prototype_obj;
    ASObject* own_props;
    u8 captured_scope_count;
    ASObject* captured_scope[8];
    MovieClip* captured_scope_mc[8];
    u8 captured_scope_is_with[8];
    MovieClip* base_clip;
    // NO swf_version field
} ASFunction;
```

### MovieEntry (has version, unused at runtime)
```c
// Generated by verify_output.py for each child SWF
typedef struct MovieEntry {
    const char* filename;
    void** frame_funcs;
    void (*init_func)(SWFAppContext*);
    int swf_version;      // Populated but never used at runtime
    int frame_count;
    int stage_width;
    int stage_height;
} MovieEntry;
```

### Version-Dependent Behavior Patterns (86 checks, 18 patterns)

| Pattern | Count | Example |
|---------|-------|---------|
| Closure support (SWF >= 6) | 16 | `base_clip` context switching |
| String coercion (SWF >= 7) | 10 | `"undefined"` vs `""` for undefined values |
| Case sensitivity (SWF < 7) | 6 | `strcasecmp` vs `strcmp` for property names |
| Number parsing (SWF >= 6) | 5 | Hex/octal parsing |
| Constructor availability (SWF >= 6/7) | 6 | Which built-in classes exist on `_global` |
| TextField props (SWF >= 8) | 4 | Additional properties available |
| Switch fallthrough (SWF <= 6) | 2 | Different switch statement behavior |
| Trace whitespace (SWF <= 7) | 1 | Condense trailing whitespace |

## Phase 1: Child SWF Version Restoration (Trivial)

**Goal:** When a child SWF is loaded, execute its init/frame scripts with its own SWF version.

### Implementation

In `actionGetURL2()` (action.c ~line 21566-21591), before calling `entry->init_func()`:

```c
// Save parent version
int saved_swf_version = g_swf_version;

// Switch to child's version
g_swf_version = entry->swf_version;

// Run child init + frame 0
entry->init_func(app_context);
if (entry->frame_funcs && entry->frame_funcs[0]) {
    ((void(*)(SWFAppContext*))entry->frame_funcs[0])(app_context);
}

// Restore parent version
g_swf_version = saved_swf_version;
```

Same change needed in the MovieClipLoader load path.

**Risk:** Low — only affects the init execution window. All subsequent frame scripts still use global version (fixed in Phase 3).

### Files to Modify
- `action.c`: `actionGetURL2()` — save/restore `g_swf_version` around child init

## Phase 2: Per-Version Global Object (Medium)

**Goal:** SWF7+ loaded movies get their own `_global` with version-appropriate constructors. SWF1-6 movies share one global.

### Ruffle's Model
- SWF versions 1-6 share a single `_global` object
- SWF version 7 gets its own `_global`
- SWF version 8 gets its own `_global`
- SWF version 9+ gets its own `_global`
- Each `_global` is populated with constructors appropriate for that version

### Implementation

#### 2a. Global object table

Replace single `global_object` with a version-keyed table:

```c
#define MAX_SWF_VERSION 12
static ASObject* g_global_objects[MAX_SWF_VERSION + 1] = {0};  // index = swf_version
static ASObject* g_shared_global_v6 = NULL;  // Shared by SWF 1-6

static ASObject* getGlobalForVersion(int version) {
    if (version <= 6) {
        if (!g_shared_global_v6) {
            g_shared_global_v6 = createGlobalObject(6);
        }
        return g_shared_global_v6;
    }
    if (!g_global_objects[version]) {
        g_global_objects[version] = createGlobalObject(version);
    }
    return g_global_objects[version];
}
```

#### 2b. Version-gated constructor population

Extract the constructor population from `actionGetGlobalObject()` into `createGlobalObject(int version)`:

```c
static ASObject* createGlobalObject(int version) {
    ASObject* obj = createASObject(64);

    // Always available (all versions)
    registerBuiltin(obj, "Object", ...);
    registerBuiltin(obj, "Array", ...);
    registerBuiltin(obj, "String", ...);
    registerBuiltin(obj, "Number", ...);
    registerBuiltin(obj, "Boolean", ...);

    if (version >= 6) {
        registerBuiltin(obj, "Date", ...);
        registerBuiltin(obj, "TextField", ...);
        registerBuiltin(obj, "TextFormat", ...);
        // ... more v6+ constructors
    }
    if (version >= 7) {
        registerBuiltin(obj, "XML", ...);
        registerBuiltin(obj, "XMLNode", ...);
        // ... more v7+ constructors
    }
    if (version >= 8) {
        registerBuiltin(obj, "TextRenderer", ...);
        // ... more v8+ constructors
    }

    return obj;
}
```

#### 2c. Global resolution update

In `actionGetVariable()`, when resolving `_global`:
```c
if (strcmp(var_name, "_global") == 0) {
    // Use current version's global
    return getGlobalForVersion(g_swf_version);
}
```

Also update scope chain fallback (lines 17760-17787) to use versioned global.

#### 2d. Track active global per MovieClip

Each MC needs to know which global it belongs to. Options:
- **Option A:** Store `swf_version` on each MovieClip, derive global from version
- **Option B:** Store `ASObject* mc_global` pointer directly on MovieClip

Option A is simpler since MovieClip already has space, and the version→global mapping is cheap.

Add to the MovieClip struct or display object:
```c
u16 mc_swf_version;  // SWF version this MC belongs to
```

Set during `loadMovie`:
```c
target_mc->mc_swf_version = entry->swf_version;
```

### Files to Modify
- `action.c`: replace `global_object` with version table, extract `createGlobalObject()`
- `action.c`: update `actionGetVariable("_global")` to use versioned lookup
- `swf.h` or display object struct: add `mc_swf_version` field
- `action.c`: `actionGetURL2()` — set `mc_swf_version` on target MC

## Phase 3: Per-Function SWF Version Tracking (Medium-Large)

**Goal:** Functions remember and execute with the SWF version they were defined in.

### Implementation

#### 3a. Add version field to ASFunction

```c
typedef struct ASFunction {
    // ... existing fields ...
    MovieClip* base_clip;
    u16 swf_version;       // NEW: SWF version at definition time
} ASFunction;
```

#### 3b. Set version at definition time

In `actionDefineFunction()` and `actionDefineFunction2()`:
```c
func->swf_version = (u16)g_swf_version;
```

For built-in functions created during global init:
```c
func->swf_version = version;  // Use the version passed to createGlobalObject()
```

#### 3c. Version context switch on function calls

In `actionCallFunction()` and `actionCallMethod()`, where closure context is already switched:

```c
// Existing closure context switch (SWF6+)
if (func->base_clip) {
    saved_context = g_current_context;
    g_current_context = func->base_clip;
}

// NEW: version context switch
int saved_version = g_swf_version;
g_swf_version = func->swf_version;

// ... execute function ...

// Restore
g_swf_version = saved_version;
if (saved_context) g_current_context = saved_context;
```

This must be done in ALL function call sites:
1. `actionCallFunction()` — both simple and advanced paths
2. `actionCallMethod()` — all method dispatch paths (OBJECT, MOVIECLIP, STRING, etc.)
3. `actionNewMethod()` / `actionNewObject()` — constructor calls
4. `invokePropertyGetter()` / `invokePropertySetter()` — addProperty callbacks
5. `invokeResolveFunction()` — __resolve hook
6. `fireTimerCallback()` — timer callbacks
7. `actionDispatchEnterFrameHandlers()` — enterFrame callbacks
8. Various event dispatch functions (mouse, key, focus)

#### 3d. Audit version-dependent sites

All 86 `g_swf_version` checks will automatically use the function's version because `g_swf_version` is a global that's swapped. However, verify no caching or pre-computed version-dependent values exist.

### Risk
Medium — touching all function call sites is error-prone. Need comprehensive regression testing.

### Files to Modify
- `action.c`: ASFunction struct + all definition sites + all call sites
- `action.c`: timer, enterFrame, event dispatch — version save/restore

## Phase 4: DoInitAction for Child SWFs (Medium)

**Goal:** Child SWF DoInitAction scripts run in the child's context, not the parent's.

### Current Behavior

DoInitAction scripts are emitted as `script_N()` calls in `tagInit()`. When `entry->init_func()` runs, it calls the child's `tagInit()` which executes DoInitAction scripts. But `g_current_context` is still set to the parent's target MC.

### Expected Behavior

For the `do_init_action_child` test:
```
=== DoInitAction #1          // Parent's DoInitAction — this: _level0, is root: true
=== Child DoInitAction #1    // Child's DoInitAction — this: child MC, is root: false
=== Assets DoInitAction #2   // Assets DoInitAction — this: child MC, is root: false
```

### Implementation

#### 4a. Context switch during child init

In `actionGetURL2()`, set `g_current_context` to the target MC before calling `init_func`:

```c
MovieClip* saved_context = g_current_context;
g_current_context = target_mc;  // Child's root is the target MC
g_swf_version = entry->swf_version;

entry->init_func(app_context);

g_current_context = saved_context;
g_swf_version = saved_version;
```

#### 4b. "Is root" detection

The test checks `this == _root`. In the child SWF context, `_root` should resolve to the child's root MC (the target MC where it was loaded). This may need:
- Setting `_root` to point to the target MC during child execution
- Or the child's `this` resolving to the target MC (which is correct since `g_current_context` is set)

#### 4c. Sprite-specific DoInitAction routing

DoInitAction has a sprite ID field. For sprite ID 0, it targets the SWF root. For sprite ID N, it targets a specific sprite definition. The recompiler currently ignores the sprite ID. To handle this:

1. **Recompiler change**: Track which DoInitAction maps to which sprite ID
2. **Runtime change**: Defer sprite-specific DoInitAction until that sprite is first placed on the display list

This is complex and may not be needed for the immediate test (which uses root-level DoInitAction).

### Files to Modify
- `action.c`: `actionGetURL2()` — context switch around init_func
- `action.c`: `_root` resolution — respect child SWF root
- Possibly `action.cpp` (recompiler): sprite ID tracking for DoInitAction

## Phase 5: RegisterClass in Child SWFs (Small)

**Goal:** Each child SWF's RegisterClass calls register classes in a version-appropriate registry.

### Current State

`g_registered_classes[128]` is a single global array. When a child SWF calls `Object.registerClass("MyClass", MyCtor)`, it registers in the parent's registry, potentially overwriting or conflicting.

### Implementation

Per-version or per-movie class registries:
```c
static RegisteredClassEntry* g_class_registries[MAX_SWF_VERSION + 1] = {0};
```

Or simpler: prefix class names with the source SWF identifier when registering from child SWFs.

### Dependency
This depends on Phases 1-2 (version tracking and context). Should be straightforward once those are in place.

## Phase 6: Variable Clearing on Reload (Small)

**Goal:** When `loadMovie` replaces a clip's content, properly clear its variable state.

### Current Behavior
`actionGetURL2()` clears `dynamic_props` on the target MC. For root replacement, it also clears the global var table.

### Missing
- For non-root clips: var_map entries referencing the clip's path are not cleared
- Timeline variables from the old SWF persist

### Implementation
Clear the target MC's dynamic_props and any var_map entries scoped to that MC path.

## Implementation Priority

| Phase | Effort | Impact | Dependencies |
|-------|--------|--------|-------------|
| Phase 1: Version restoration | Trivial (~10 lines) | Enables child SWF to init with correct version | None |
| Phase 2: Per-version global | Medium (~200 lines) | 4+ tests, enables version-appropriate constructors | Phase 1 |
| Phase 3: Per-function version | Medium-Large (~150 lines, many call sites) | All cross-version function calls | Phase 1 |
| Phase 4: DoInitAction context | Medium (~50 lines) | 1 test directly, enables child class init | Phase 1 |
| Phase 5: RegisterClass isolation | Small (~50 lines) | 3 tests | Phases 2+3 |
| Phase 6: Variable clearing | Small (~30 lines) | 1 test | Phase 1 |

**Recommended order:** Phase 1 → 4 → 2 → 3 → 5 → 6.

Phase 1 is trivial and enables testing of all subsequent phases. Phase 4 is high-value because it unblocks DoInitAction which many tests need. Phase 2 unblocks the global isolation tests. Phase 3 is the most invasive but necessary for full correctness.
